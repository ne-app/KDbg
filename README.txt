Ant Kernel Debugger
--------------------------------------------------------------------------------------------------------------

The Ant kernel debugger for the Ant PDK and its distributions.

--------------------------------------------------------------------------------------------------------------
Installing
--------------------------------------------------------------------------------------------------------------

The Software Git, GCC, OCL, Avkon, Boost, and their depedencies are required before proceeding to install.

--------------------------------------------------------------------------------------------------------------
Installing Steps
--------------------------------------------------------------------------------------------------------------

- Build the KDbg DLL.
- Build the CLI from the KDbg DLL.
