Kernel Debugger
===============

The Kernel debugger for the Ant PDK and its distributions.

Installing
==========

Git, GCC, OCL, Avkon, Boost, and their depedencies are required before proceeding to install.

Steps:
=======

- Build the KDbg DLL.
- Then once you're done, build the cli DLL.
